## 建议阅读路径

- **只想尽快跑起来** — 先看仓库根目录 [README](../README.md) 的「快速开始」两条命令，出问题再翻运维手册的故障排查。
- **想弄懂原理再动手** — 背景与架构 → 服务器端配置 → 客户端配置 → 任意客户端接入。
- **担心安全或要过审** — 能力、限制与风险 → 运维手册的安全加固清单 → [SECURITY.md](../SECURITY.md)。
- **机器老是被重启** — 保活与平台定时重启。
- **机器被休眠 / 关机，连不上了** — 冷启动与唤醒。
- **已经跑起来了，想加客户端** — 任意客户端接入 + 接口契约。

## 术语速查

| 词 | 含义 |
|---|---|
| 网关（gateway） | 服务器上的小程序 `gateway.js`，只听回环地址的话，按请求办事 |
| 隧道（tunnel） | 从公网牵到网关的加密通道，解决「服务器没有公网 IP」 |
| 令牌（token） | 64 位十六进制随机串，每次请求都要带；泄露等于控制权泄露 |
| 白名单（roots） | 允许被访问的目录集合，路径一律用绝对路径 |
| 控制面 | 路径以 `/__agent/` 开头的接口；其余路径可反代给原有网站 |
