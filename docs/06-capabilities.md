# 能力、限制与风险

## 总览

### 能实现什么、不能实现什么

**能实现（开箱即用）**

| 能力 | 说明 |
|---|---|
| 白名单目录列目录 | `list`，最多 500 项 |
| 白名单内读写文件 | `read` / `write`；文本与二进制（`encoding=base64`）都支持，写前自动备份 |
| 查系统状态 | `sysinfo`：系统版本、CPU 数、内存、运行时长；`health`：网关版本、进程、白名单、命令开关 |
| 查操作审计 | `log`：每次调用的时间、来源、动作、成败、耗时 |
| 反代保留原有网站 | 非 `/__agent/*` 的请求原样转发给服务器上已有站点，不改端口、不动原服务 |
| 任意客户端接入 | curl / Python / Node / CI / 自定义动作 / MCP / 纯对话贴结果，都只认「HTTPS POST + Bearer + JSON」 |
| 两步自动部署 | 服务器一条命令、本机一条命令；自动建目录、生成令牌、注册自启与看门狗、跑完 8 项验证 |
| 重启后自动恢复 | 登录自启 + 分钟级看门狗 + 隧道自启 + 客户端重试；实测恢复窗口约 1～2 分钟 |

**有条件才能实现**

| 能力 | 条件 |
|---|---|
| 远程执行 PowerShell / cmd / shell | 必须显式设 `execEnabled=true`（一键脚本加 `-EnableExec` / `--enable-exec`）；命令非交互、必带超时、受 `execDeny` / `execAllow` 约束，危险命令被拒绝 |
| 中文与二进制内容 | 用 `encoding=base64` 取原始字节，再按 `gb18030` / `utf-8` 解码；写回时按原编码编码 |
| 超过 2 MB 的文件 | 先在服务器侧压缩 / 切片，分次 `read`；单次读上限 2 MB、请求体上限 5 MB |
| 长时间任务 | 单次 `exec` 超时上限 600 秒、输出上限 64 KB；长任务改成后台任务 + 结果写文件再读 |
| 图形界面软件 | 本方案不提供 GUI；需要厂商自家客户端操作桌面，本方案只做确定性的文件与命令接口 |
| 多人分权使用 | 网关是单令牌、无 RBAC；要分权请自建带各自凭据的代理层，或改用官方多用户方案 |
| 云端 AI 客户端直连 | 必须有公网可达的隧道地址；内网 / `127.0.0.1` 云端访问不到 |

**不能实现（别踩坑）**

| 做不到 | 原因 |
|---|---|
| 访问白名单之外的路径 | 路径白名单 + `denyRead` / `denyWrite` 双重限制；`config.json`、私钥类文件默认禁读 |
| 鼠标键盘级 GUI 操作、看屏幕、点弹窗 | 没有桌面通道，只有 HTTP 控制面 |
| 交互式命令、等待输入、安装向导 | `stdin` 被关闭，命令一律非交互，必带超时 |
| 流式输出、长连接、大文件直传 | 协议是「一次 POST / 一次 JSON 响应」 |
| 多用户 RBAC、细粒度权限、配额隔离 | 单令牌设计 |
| 阻止平台强制关机 / 定时重置 / 宿主层断电 | 属于平台与宿主机行为，虚拟机内部拦不住；见 [保活与平台定时重启](03-keepalive.md) |
| 在没有公网入口时让云端模型访问内网服务器 | 云端模型只能访问公网地址，必须有隧道 |
| 替代数据库客户端、图形化运维工具、厂商桌面同步能力 | 能力边界就是文件 + 命令 + 状态 + 审计 |
| 把令牌安全地「交给不可信的第三方」 | 拿到令牌就等于拿到同等控制权；只能交给可信服务并定期轮换 |

### 分层限制（默认值，可在配置中调整）

| 层 | 限制 | 影响 |
|---|---|---|
| 网络 | 网关只绑回环；公网靠单一隧道 | 隧道断 = 全断；免费隧道域名会变、可能限速 |
| 厂商 | 无公网 IP、无对外 API、空闲自动关机、连接数上限 | 必须做开机自启 + 失败重启 + 隧道自启 |
| 协议 | 控制面只收 `POST` + JSON（HTTPS 由隧道提供）；请求体 ≤5 MB；非控制面路径可 GET 并反代 | 不适合大文件、长连接、流式传输 |
| 文件 | 单次读 ≤2 MB、单次列目录 ≤500 项、路径白名单 | 大文件要先在服务器侧压缩分片 |
| 命令 | 默认关闭；命令 ≤8000 字符；超时默认 60 s / 上限 600 s；stdout ≤64 KB、stderr ≤16 KB；并发 ≤3 | 长任务要改成后台任务 + 输出写文件再读 |
| 频率 | 默认 180 次 / 分钟 | 高频轮询要加退避 |
| 客户端 | 云端 AI 只能访问公网地址；浏览器直连受 CORS 限制 | 需要隧道 / 同源代理 |
| 平台 | Windows 与 Linux 路径分隔符、编码、shell 都不同 | 配置必须按系统分别填 |

### 风险登记表

| 风险 | 后果 | 缓解 |
|---|---|---|
| 令牌泄露 | 对方获得同等控制权限 | 只放 0600 文件 / 环境变量；不进聊天、仓库、配置模板；定期轮换；轮换时同步所有客户端 |
| 隧道地址被扫描 | 未授权探测 | 固定域名 + 隧道侧认证 / IP 白名单；网关仍只绑回环 |
| 白名单给太大 | 可读到网关配置、私钥等敏感文件 | 白名单只给必要目录；`denyRead` 模板默认拒绝 `config.json`、`*.key` / `*.pem` / `*.pfx` / `*.p12`、`id_rsa`、`.ssh/` |
| 开启命令执行 | 误操作 / 被滥用 | 默认关闭；`execDeny` 拒绝危险命令；生产再配 `execAllow` 只允许必要命令；最小权限运行账户 |
| 命令没有交互 | 卡到超时 | 一律非交互、必带超时；禁止 `pause`、自提权脚本 |
| 审计不足 | 出事查不到 | 每次调用记时间 / 来源 / 动作 / 成败 / 耗时；日志定期归档 |
| 自动备份堆积 | 磁盘被占满 | 定期清理 `backups/`；写操作尽量幂等 |
| 单点故障 | 网关崩了全断 | 服务级 `Restart=always` / 计划任务失败重启；保留回退配置 |
| 合规 | 违反厂商条款 / 越权访问 | 只用自有或已授权机器；先读服务条款 |

### 与厂商原生能力的边界

厂商自家客户端负责「整机桌面、GUI 软件、任务记忆、多端同步」；本方案负责「确定性文件与命令接口」。两者不冲突：一次性装软件、需要 GUI 的活，用厂商客户端；需要脚本化、可复现、可审计的活，用本方案。若厂商提供官方 SDK / MCP，生产环境优先用官方。
